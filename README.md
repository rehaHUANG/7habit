# 國中生的七個好習慣｜GitHub Pages

這是依《漫畫讀通：與成功有約》整理的國中生導讀網站，包含七個習慣簡介、生活例子、一週行動地圖、個人反思欄位，以及文件提供的三項延伸連結。網站只連至外部 Google Drive 和 YouTube，不複製或託管原書及雲端教材；檢視權限由各外部服務的分享設定決定。

## 發布網站

本儲存庫使用 GitHub Actions 自動發布靜態網站。將更新推送到 `main` 後，請在 Actions 頁面確認 **Deploy static site to GitHub Pages** 完成；網站網址為 `https://rehahuang.github.io/7habit/`。

反思欄與習慣完成進度會儲存在瀏覽器的本機儲存空間，不會送到伺服器。
