# 國中生的七個好習慣｜GitHub Pages

這是依《漫畫讀通：與成功有約》整理的國中生導讀網站，包含七個習慣簡介、生活例子、一週行動地圖與個人反思欄位。頁面提供摘要與學習活動，不包含原書 PDF、掃描頁或班級雲端教材。

## 發布網站

1. 將本資料夾內容放入 GitHub repository 根目錄。
2. 在 repository 的 **Settings → Pages** 選擇 **Deploy from a branch**。
3. 選 `main` 分支與 `/(root)` 資料夾後儲存。
4. 等待部署完成，使用 Pages 顯示的網址瀏覽網站。

反思欄與習慣完成進度會儲存在瀏覽器的本機儲存空間，不會送到伺服器。
